# Design review checklist

Document coverage checked against the reference HLD topic:

- [x] Student/admin functional requirements and scope.
- [x] Quality targets, workload assumptions and capacity math.
- [x] Architecture diagram, responsibilities and deployment choice.
- [x] Relational data model, indexes and private object storage.
- [x] Public API contracts and authorization.
- [x] Cache, queue, outbox and idempotency decisions.
- [x] Worker pools, isolation, hidden-test handling and resource limits.
- [x] Concurrent submissions, fencing, retries and duplicate-result protection.
- [x] Rate limiting, backpressure, high availability and disaster recovery.
- [x] Security, human-reviewed plagiarism signals and auditability.
- [x] Monitoring, failure cases and tradeoffs.
- [x] Five-minute presentation guide.

These ticks mean the design addresses the topic. They do not mean a service was deployed or its performance/security targets experimentally proven. Instructor review and explanation by the submitter remain necessary.
